# beachwise-mcp

beachwise mcp server is a proof of concept for building mcp servers with typescript and external APIs.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues ([alirezashamsaei/beachwise-mcp](https://github.com/alirezashamsaei/beachwise-mcp), via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
